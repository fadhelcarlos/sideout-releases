# sideout · releases

sideout for Android and iPhone.

- **Android:** [download the latest signed APK](https://github.com/fadhelcarlos/sideout-releases/releases/latest/download/sideout.apk). Every version installs over the previous one; the app updates itself.
- **iPhone:** TestFlight, from [sideoutpr.com](https://sideoutpr.com).
- **Web:** [sideoutpr.com/app](https://sideoutpr.com/app).

This repository holds the signed builds and the workflows that produce them from the private source.
